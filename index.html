Try to break it

Pick an attack. Each one is stopped by code I wrote, and a test proves it on every change.

  • Send a tampered login token. The API refuses tampered and revoked tokens. LabaLink · tamperedAndRevokedTokensAreRejected · passed
  • Keep guessing a password. After five failures the account locks, even if the next guess is right. InkHive · test_lockout_after_five_failures_even_with_right_password · passed
  • Upload a web page renamed as a photo. Uploads are checked by what they contain, not by their name. InkHive · test_html_disguised_as_image_rejected · passed
  • Fake a Stripe payment. A webhook without Stripe's signature is rejected, so no wallet is credited. LabaLink · forgedWebhooksAreRejected · passed
  • Flood the whiteboard with messages. Messages over the limit are dropped and malformed ones ignored. InkHive · test_flooding_is_capped_and_garbage_ignored · passed
  • Sign up as an admin. Sign-up can't create an admin account. InkHive · test_cannot_sign_up_as_admin · passed
  • Type SQL into the menu search. Search treats markup and SQL as plain text. Seoul-Mate · treats markup and SQL as plain text that matches nothing · passed

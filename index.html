PlayIT

Offline English phonics app for Grade 1 learners

Capstone, team of 5

Kotlin, Jetpack Compose, Clean Architecture + MVVM, Room, Hilt, Vosk speech recognition

Team repo on GitHub
  • An offline-first Android app for 2 GB phones that teaches Marungko phonics with on-device speech recognition.
  • Child-friendly accessibility: sound captions, mouth-shape cues, 64 dp touch targets, and "no red" feedback.
  • Fixed core Blend It game logic so tiles are never dealt in answer order, and wrote the SRS, SDD, and test docs.
  • Release QA: a Python tool that stops the submission if any number disagrees with the JUnit results or APK checksum.

Real-time collaborative whiteboard for classrooms

Lead and backend developer, team of 3

Python, Django 5.2, WebSockets, SQLite, PostgreSQL, JavaScript

Source on GitHub
